# Logo

The brand as inline SVG: `wordmark` (pklnx, star, space in the space bar) or `mark` (space bar with star).

- The wordmark is set in IBM Plex Mono (`pklnx` Bold, `space` Regular) and converted to paths. Eleven characters on the monospace grid, the star sits in the cell of the space.
- Text and bracket follow CSS `color` (default `text-primary`). The star is always `star`, except with `mono`.
- Height in px through `height`. Wordmark at least 20px high, mark at least 16px.
- Clear space all around: the height of the star, about 0.3 × the wordmark height.
- For files (email, print, social) use the SVGs from the Logos group, not the inline SVG.
- The consumer only provides the height and, if needed, a `title` for screen readers.
