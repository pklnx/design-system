# Icon

Carbon Icons (`@carbon/icons-react`) unter kurzen pklnx-Namen, dazu der Stern als einziges eigenes Zeichen.

- Größen 16, 20, 24 oder 32px. Neben Text und in Buttons 16px (`icon-size-01`), allein und in der Kopfzeile 20px (`icon-size-02`).
- Farbe über `currentColor`, Standard `icon-primary`. Ein Icon ohne Text braucht `label`.
- Namen: `terminal`, `server`, `mail`, `cloud`, `shield`, `key`, `lock`, `database`, `globe`, `arrow-right`, `external`, `check`, `close`, `copy`, `star`.
- Fehlt ein Icon, das passende aus der Carbon-Bibliothek nehmen (carbondesignsystem.com/elements/icons/library) und in `ICONS` ergänzen. Keine fremden Icon-Sets, keine Emoji.
- `star` ist gefüllt in `star` und nur für Hervorhebungen gedacht, nie als Aufzählungszeichen.
