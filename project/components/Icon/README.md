# Icon

Carbon Icons (`@carbon/icons-react`) under short pklnx names, plus the star as the only drawing of our own.

- Sizes 16, 20, 24 or 32px. Next to text and in buttons 16px (`icon-size-01`), on their own and in the header 20px (`icon-size-02`).
- Color through `currentColor`, default `icon-primary`. An icon without text needs a `label`.
- Names: `terminal`, `server`, `mail`, `cloud`, `shield`, `key`, `lock`, `database`, `globe`, `arrow-right`, `external`, `check`, `close`, `copy`, `star`.
- If an icon is missing, take the matching one from the Carbon library (carbondesignsystem.com/elements/icons/library) and add it to `ICONS`. No other icon sets, no emoji.
- `star` is filled in `star` and meant for emphasis only, never as a bullet.
