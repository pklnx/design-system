# LogoUsage

Overview of the logo variants on both grounds, clear space, minimum sizes and single-color use.

- G100: wordmark in `text-primary` (#f4f4f4), star `star` (Purple 50 #a56eff). White: wordmark `text-primary` (#161616), star `star` (Purple 60 #8a3ffc).
- Single color only when the print allows no second color. Then the star takes the text color too.
- Never stretch, reset, recolor (except single color), replace the star with a dot, or add shadows, gradients or outlines.
- Never on busy photos. If needed, place it on a `background` area.
