# LogoUsage

Übersicht der Logo-Varianten auf beiden Gründen, Schutzraum, Mindestgrößen und einfarbige Anwendungen.

- G100: Wortmarke in `text-primary` (#f4f4f4), Stern `star` (Purple 50 #a56eff). White: Wortmarke `text-primary` (#161616), Stern `star` (Purple 60 #8a3ffc).
- Einfarbig nur, wenn der Druck keine zweite Farbe erlaubt. Dann auch der Stern in der Textfarbe.
- Nie verzerren, neu setzen, umfärben (außer einfarbig), den Stern durch einen Punkt ersetzen, Schatten, Verläufe oder Konturen hinzufügen.
- Nie auf unruhigen Fotos. Wenn nötig, auf eine `background`-Fläche setzen.
