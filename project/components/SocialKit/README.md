# SocialKit

Vorlagen für Open-Graph-Bild, Avatar und Banner. Die fertigen Dateien liegen in den Asset-Gruppen Social und Logos.

- Open Graph: `pklnx-og-image.svg`, als PNG 1200 × 630 exportieren und im `<head>` als `og:image` einbinden.
- Avatar: `pklnx-avatar.svg`, für GitHub, Gravatar, LinkedIn. Mindestens 400 × 400 px als PNG.
- Banner: `pklnx-banner.svg` als Kopfbild im GitHub-Profil-README.
- Immer G100 (`#161616`). Keine Fotos hinter der Marke. Erzeugt von `scripts/build_assets.py`.
