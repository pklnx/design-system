# SocialKit

Templates for the Open Graph image, avatar and banner. The finished files are in the Social and Logos asset groups.

- Open Graph: `pklnx-og-image.svg`, export as PNG at 1200 × 630 and add it to `<head>` as `og:image`.
- Avatar: `pklnx-avatar.svg`, for GitHub, Gravatar, LinkedIn. At least 400 × 400 px as PNG.
- Banner: `pklnx-banner.svg` as the header image of the GitHub profile README.
- Always G100 (`#161616`). No photos behind the brand. Generated by `scripts/build_assets.py`.
