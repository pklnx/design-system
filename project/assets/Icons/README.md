# Icons

Carbon Icons (IBM, Apache-2.0) as SVG, 32 × 32, single color in `text-primary` White (`logo.light.ink` in `theme/brand.json`). `star.svg` is our own drawing (`icon.star` in `theme/logo-geometry.json`), filled in the White star color (`logo.light.star`). For dark grounds and other colors use the `Icon` component, which uses `currentColor`. Generated by `scripts/build_icons.mjs`.
