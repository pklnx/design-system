# Product logos

The marks, lockups and app icons of the pklnx products **mail-archive** and **paperless-go**. They use the formal language of the pklnx mark: the 64-unit grid, 7-unit strokes, square corners and the four-pointed star as the only accent.

- **mail-archive**: an archive box, a lid bar over an open box, with the star as the label.
- **paperless-go**: a file, a page with the top-right corner folded, with the star on the page.

All files are generated by `scripts/build_product_logos.py` (SVG) and `scripts/render_pngs.mjs` (PNG); do not edit them by hand. The name in the lockups is IBM Plex Mono SemiBold, converted to paths, so the files need no fonts.

## Files

`P` is `mail-archive` or `paperless-go`.

| File | Use in the product |
| --- | --- |
| `P-tile.svg` | 64 × 64 tile on `#161616` with 22 % corners, as `pklnx-favicon.svg`. The SVG favicon (`web/src/logo.svg`), the app header, the login page, the docs favicon. |
| `P-favicon-32.png` | 32 px favicon, from the tile: `<link rel="icon" type="image/png" sizes="32x32">`. |
| `P-icon-192.png`, `P-icon-512.png` | PWA icons from the tile, `purpose: "any"` in `manifest.webmanifest`. |
| `P-apple-touch-icon.png` (180 px), from `P-apple-touch-icon.svg` | `<link rel="apple-touch-icon">`. A full-bleed square; iOS rounds the corners itself. |
| `P-icon-maskable-512.png`, from `P-icon-maskable.svg` | PWA icon with `purpose: "maskable"`. The mark is centred and lies inside the safe circle (radius 0.4 × size), so any mask shape keeps it whole. |
| `P-mark-dark.svg`, `-light.svg` | The mark alone, transparent: ink `#f4f4f4` and star `#a56eff` on G100, ink `#161616` and star `#8a3ffc` on White. The docs nav logo (`themeConfig.logo` with `{ light, dark }`). |
| `P-mark-black.svg`, `-white.svg` | Single colour, where the medium allows only one. |
| `P-lockup-dark.svg`, `-light.svg`, `-black.svg`, `-white.svg` | Mark and name, transparent, for the README header (`<picture>` with the dark and light file) and printed matter. |
| `manifest.json` | Generated: every PNG with its size, source SVG, source sha256 and PNG sha256. The tests use it to catch a stale PNG. |

The social images (`project/assets/Social/P-social.svg` and `.png`, 1280 × 640) are the repository's social preview and Open Graph image.

## Rules

- **Lockup**: the mark is scaled so its 7-unit stroke equals the stem of the SemiBold `l`, its box is centred on the cap height, and the name starts half a character cell after the box. An HTML title in IBM Plex Mono SemiBold (the VitePress nav title, for example) next to the mark matches the lockup.
- **Clear space**: around the mark, 7 units of its grid (one stroke); around the lockup, the height of the name's `x`.
- **Minimum size**: tile and mark 16 px, lockup 20 px high.
- **Don'ts**, as in `LogoUsage`: never stretch, rotate, recolour (except single colour), outline or shadow the marks, never replace the star, never set the name in another font, and never place them on busy photos.
