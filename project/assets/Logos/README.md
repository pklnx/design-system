# Logos

- `pklnx-wordmark-dark.svg`: text and bracket `#f4f4f4`, star `#a56eff` (Purple 50). On G100 `#161616`.
- `pklnx-wordmark-light.svg`: text and bracket `#161616`, star `#8a3ffc` (Purple 60). On White.
- `pklnx-wordmark-black.svg` / `-white.svg`: single color for stamps, engraving, fax, vinyl.
- `pklnx-mark-dark.svg`, `-light.svg`, `-black.svg`, `-white.svg`: the mark, same colors as above.
- `pklnx-favicon.svg`: 64 × 64 tile on `#161616`, 22 % corners. Use as `favicon.svg`, also export a 32 px PNG and a 180 px Apple touch icon.
- `pklnx-avatar.svg`: circle on `#161616` for GitHub, LinkedIn, Gravatar.
- Wordmark from IBM Plex Mono (Bold and Regular), converted to paths. The files need no fonts. Generated by `scripts/build_logo.py`.
