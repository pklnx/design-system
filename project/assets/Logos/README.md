# Logos

- `pklnx-wordmark-dark.svg`: Text und Klammer `#f4f4f4`, Stern `#a56eff` (Purple 50). Auf G100 `#161616`.
- `pklnx-wordmark-light.svg`: Text und Klammer `#161616`, Stern `#8a3ffc` (Purple 60). Auf White.
- `pklnx-wordmark-black.svg` / `-white.svg`: einfarbig für Stempel, Gravur, Fax, Folie.
- `pklnx-mark-dark.svg`, `-light.svg`, `-black.svg`, `-white.svg`: Bildmarke, gleiche Farben wie oben.
- `pklnx-favicon.svg`: Kachel 64 × 64 auf `#161616`, Ecken 22 %. Als `favicon.svg` einbinden, zusätzlich 32 px PNG und 180 px Apple-Touch-Icon exportieren.
- `pklnx-avatar.svg`: Kreis auf `#161616` für GitHub, LinkedIn, Gravatar.
- Wortmarke aus IBM Plex Mono (Bold und Regular), in Pfade umgewandelt. Die Dateien brauchen keine Fonts. Erzeugt von `scripts/build_logo.py`.
